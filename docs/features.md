# 独自機能

upstream(`syuilo/ai`)に対して、このフォークで追加・変更した機能。
バージョンごとの変更は [changelog.md](changelog.md) を参照。

## 学習した語句(キーワード)

`keyword` モジュールが、30分ごとにグローバルタイムラインのノートを形態素解析して、固有名詞を1つ覚える。
覚えた語句はコレクション `_keyword_learnedKeywords`(`{ keyword, learnedAt }`)に保存される。

### 覚える語句

- 固有名詞で、読みがあるもの(辞書にない語や、読みがカタカナでない語は覚えない)。
- 人名は、名字・名前だけのもの(細分類が「姓」「名」)を覚えない。
  キャラクター名(例: 初音ミク)や、辞書にフルネームで載っている有名人の名前(細分類が「一般」)は覚える。
  一般の人の名前は辞書に載っていないため、名字と名前に分かれて除外される。
- 形態素解析は MeCab と Sudachi を選べる。詳しくは [morph-analyzer.md](morph-analyzer.md)。

### 忘れる

覚えてから30日を過ぎた語句を、1日ごとに5%の確率で忘れる(平均の寿命は約50日)。
語句が増え続けると、新しく覚えた語句が埋もれるため。

- 忘れる処理は、日付が変わったときに1日1回だけ行う(おみくじの結果が1日の途中で変わらないように)。
- 忘れた語句は、また見かければ覚え直す。
- 日数と確率は `src/modules/keyword/index.ts` の `FORGET_AFTER_DAYS` / `FORGET_RATE`。

### 管理コマンドと日次レポート(マスター専用)

`config.json` の `master` のユーザー(このサーバのローカルユーザー)だけが使える。メンションで送る。
返事は送った投稿と同じ公開範囲になるので、語句を公開したくないときはダイレクト(指定したユーザーのみ)で送る。

| コマンド | 内容 |
|---|---|
| `/keywords` | 覚えている語句の数と、最近覚えた10個を返す |
| `/forget 語句` | 語句を忘れて、以後も覚えないようにする(語句は完全一致。`「語句」` と括ってもよい)。まだ覚えていない語句にも使える |
| `/unforget 語句` | 覚えないようにした語句を、また覚えられるようにする |

「覚えないようにした語句」は、`keyword` モジュールのデータ(`data/memory.json`)に保存される。
不適切語句を自動で除外するロジックは入れていないので、気づいたものはこのコマンドで消す。

日付が変わったとき(忘れる処理と同じ)に、マスターへチャットで「覚えた/忘れた/いま覚えている」の個数と、使っている形態素解析を送る。
マスターが未設定の場合や、チャットを送れなかった場合は、何もせずログに残す。
起動時にも、使っている形態素解析をログに出す(`Morph analyzer: …`)。

`KeywordModule` は `src/index.ts` で `CoreModule` の次に置いている。
コマンドの語句にトークの反応語(「すき」など)が含まれていても、先にコマンドとして処理されるようにするため。

### 使われる場所

共通処理は `src/utils/gen-item-with-keyword.ts`。
`genItemWithKeyword()` は、30%(`KEYWORD_RATE`)の確率で学習した語句を使い、それ以外は従来の `genItem()` を使う。
学習した語句は、10文字(`KEYWORD_MAX_LENGTH`)以下のものだけを使い、8割の確率で接頭辞(「伝説の」など)を付ける。

| 機能 | 使い方 |
|---|---|
| あだ名(`talk`) | 提案するあだ名に使う |
| アンケート(`poll`) | 選択肢に使う。学習した語句が4つ以上あれば、2割の確率で「最近覚えた言葉」だけのアンケートにする(新しい20語から重複なしで4つ) |
| おみくじ(`fortune`) | ラッキーアイテムに使う。候補は**その日の0時より前に覚えた語句だけ**にして、同じ日は同じ結果になるようにしている |
| 独り言(`noting`) | 「〇〇、欲しいなぁ...」など、アイテムを使う独り言に使う |
| 「何覚えた？」(`talk`) | 新しく覚えた順に3つ答える(長さの制限なし) |

引き継ぎコード(`friend.ts`)は `genItem()` のまま。学習した語句を混ぜると、推測しやすくなるため。

## あだ名を呼び名にする(`talk`)

「あだ名」と話しかけると、「〇〇とお呼びしてもいいですか？」と聞く。

- 「はい」「いいよ」「うん」「それで」「お願い」なら、そのまま呼び名にする。
- 「いいえ」「ううん」「やだ」「嫌」「だめ」「やめ」なら、呼び名は変えない(「ううん」は「うん」を含むので、否定を先に判定する)。
- それ以外の返信は、待ち受けをやめて普段の会話として扱う。
- 呼び名にできる条件は「〇〇って呼んで」と同じ(10文字以下、記号を含まない)。条件を満たすあだ名が出るまで最大10回考え直す。

## 親愛度

リバーシ(upstream)と同じく、ゲームで遊ぶと親愛度が上がる。どれも1日1回まで。

| ゲーム | 上がる条件 |
|---|---|
| 数取り(`kazutori`) | 勝ったとき |
| 数当て(`guessing-game`) | 正解したとき |

親愛度は、挨拶などの反応や誕生日のお祝い(親愛度3以上)に影響する。
