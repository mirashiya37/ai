# 変更履歴

このフォークのバージョン(`package.json` の `_v`)ごとの変更。付け方は [versioning.md](versioning.md)。
機能の詳細は [features.md](features.md)。

## 2.0.1-mk3.1.0

- 固有名詞を、普通名詞より多く覚えるようにした。覚える語を選ぶとき、まず固有名詞と普通名詞のどちらから選ぶかを、
  固有名詞 60% の確率で決める(これまでは種類を区別せず、固有名詞は約35%だった)。確率は `config.json` の `keywordProperRate` で変えられる。
- 覚えた語に、固有名詞か普通名詞かの `kind` を保存するようにした。ログと日次レポートに、種類ごとの数が出る。
  すでに覚えた語には `kind` がない(内訳には含まれない)。

## 2.0.1-mk3.0.1

- AI チャットで、添付ファイルを取得する処理を見直した。

## 2.0.1-mk3.0.0

- **破壊的変更: コンテナの実行ユーザーを変更した。** デプロイの前に、サーバ側でファイルの権限の設定が要る。
- ビルドに使う依存とイメージの版を固定した。

## 2.0.1-mk2.8.2

- `ws` を 8.22.0 に更新した。

## 2.0.1-mk2.8.1

- AI チャットのログの出力を見直した。
- `/poll` の実行条件を見直した。

## 2.0.1-mk2.8.0

- 普通名詞も覚えるようにした。一般的すぎる語で固有名詞の語が埋もれないよう、細分類が「一般」・3文字以上・
  英数字だけでもひらがなだけでもない語に限る(「武勇伝」「いじめっ子」など。「天気」「site」「ほんと」は覚えない)。
  「今日よく見かけた言葉」の集計にも同じ条件が使われる。すでに覚えた語はそのまま。

## 2.0.1-mk2.7.1

- **修正: Sudachi の解析が終わらなくなり、学習が止まっていた**(2.5.0 以降)。タイムラインの投稿をまとめて渡すと、出力が大きいときに
  終わらないまま止まっていた。何も覚えず、エラーも出ない状態だった。
- Sudachi に渡す投稿を、1件5000文字で切り詰めるようにした(他のサーバーの長い投稿が1件あるだけで、その回の学習がすべて失敗していた)。
- 覚える語を、まだ覚えていない語の中から選ぶようにした(覚えている語に当たって、何も起きない回をなくした)。
- 解析の前に、カスタム絵文字の記法(`:meow_sushi:` など)を取り除くようにした。絵文字名の一部(`meow` など)を覚えていた。
- 学習と、語句を忘れる処理の経過を、毎回ログに出すようにした。

## 2.0.1-mk2.7.0

- 毎日のチャートの投稿に、タイムラインで「今日よく見かけた言葉」を5個まで添えるようにした。
- 解析の前に本文から URL を取り除くようにした。`https` や URL の一部(ドメインやパス)を覚えたり数えたりしていた。

## 2.0.1-mk2.6.0

- マスター用のコマンド `/keywords`、`/forget 語句`、`/unforget 語句` を追加した。忘れさせた語句は、以後も覚えない。
- 日付が変わったときに、学習の状況(覚えた・忘れた・いま覚えている個数)をマスターにチャットで送るようにした。
- 起動時に、使っている形態素解析をログに出すようにした。

## 2.0.1-mk2.5.0

- 形態素解析に Sudachi(SudachiDict full)を使えるようにした。`config.json` の `morphAnalyzer` で選ぶ(既定は MeCab)。
  Docker イメージに Sudachi と辞書を入れた([morph-analyzer.md](morph-analyzer.md))。
- 人名の除外を、名字・名前(細分類が「姓」「名」)だけにした。キャラクター名などフルネームの名前は覚える。

## 2.0.1-mk2.4.0

- 覚えてから30日を過ぎた語句を、1日ごとに5%の確率で忘れるようにした。

## 2.0.1-mk2.3.0

- 「最近覚えた言葉」だけのアンケートを出すようにした。
- 独り言に学習した語句を使うようにした。

## 2.0.1-mk2.2.0

- 提案したあだ名を、そのまま呼び名にできるようにした。
- 「何覚えた？」に、最近覚えた語句を答えるようにした。
- 数取りの勝者と、数当ての正解者の親愛度を上げるようにした。

## 2.0.1-mk2.1.0

- あだ名・アンケート・おみくじに、学習した語句を使うようにした。
- 人名を学習しないようにした。
